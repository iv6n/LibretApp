# Task Image Assets

Task illustrations use the shared 2.5D language: centered square WEBPs with
short gradients, soft contact shadows and integrated highlights, warm
agricultural colors, simple silhouettes, no text, people, animals or
watermarks, and real RGBA transparency.

All task assets are compressed 256×256 WEBP files with RGBA transparency.
Agenda maps deworming and vaccination tasks to their specific assets and keeps
the Material icon as a runtime fallback when an asset is unavailable.

## Naming convention

Use one asset per task:

`assets/images/task_<task_type>.webp`
