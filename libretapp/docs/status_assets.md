# Status Image Assets

Status illustrations use the shared LibretApp 2.5D raster language: centered
rounded badges, warm agricultural colors, simple symbols, no text or
watermarks, and real RGBA transparency.

## Tanda 7 — Estados operativos

- `assets/images/status_pending.webp`
- `assets/images/status_completed.webp`
- `assets/images/status_overdue.webp`
- `assets/images/status_in_progress.webp`
- `assets/images/status_canceled.webp`
- `assets/images/status_critical.webp`

All Tanda 7 assets are compressed 256×256 WEBPs with real RGBA transparency.

## Tanda 8 — Estados restantes

- `assets/images/status_quarantine.webp`
- `assets/images/status_synced.webp`
- `assets/images/status_offline.webp`

These assets are also compressed 256×256 WEBPs with real RGBA transparency.

## Naming convention

`assets/images/status_<status_type>.webp`
